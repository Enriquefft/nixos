# Privacy & Security Notes

This NixOS configuration has been audited for safe public publishing.

## What's excluded (`.gitignore`)

The following files contain **personally identifiable information** (phone numbers,
email addresses, financial details, career strategy) and are not tracked:

| File | Contents | Action required |
|------|----------|-----------------|
| `openclaw/documents/USER.md` | Owner contact info, career details | Create from `USER.md.example` |
| `openclaw/documents/LORE.md` | Job-search strategy, financial runway | Create from `LORE.md.example` |
| `openclaw/reference/full-profile.md` | Full resume with phone/email | Create manually |
| `openclaw/reference/reusable-responses.md` | Personalized cover-letter templates | Create manually |
| `.claude/settings.local.json` | Local Claude tool permissions | Auto-generated by Claude |

If you clone this repo, create these files locally to restore full functionality
for the OpenClaw agent. The `.example` templates (where provided) show the
expected structure without real data.

## Secrets management

All API keys and tokens are encrypted at rest with
[sops-nix](https://github.com/Mic92/sops-nix) + age.
The SOPS file (`secrets/zeroclaw.yaml`) is safe to publish — it contains only
AES-256-GCM ciphertext that requires the matching age private key to decrypt.

## What's safe to publish

- **Username, real name, git email** — standard for public dotfiles repositories
  and already visible via git commit metadata.
- **Location / timezone** — non-sensitive context for locale configuration.
- **Hardware UUIDs** (`hardware-configuration.nix`) — disk UUIDs are
  machine-specific but pose no meaningful security risk.
- **age public key** (`.sops.yaml`) — public keys are designed to be shared.

## Git history caveat

Removing files from tracking does **not** erase them from git history.
Before making this repository fully public, run a history-rewriting tool to
scrub the old commits:

```bash
# Recommended: git filter-repo (precise, path-aware)
git filter-repo --path openclaw/documents/USER.md \
                --path openclaw/documents/LORE.md \
                --path openclaw/reference/full-profile.md \
                --path openclaw/reference/reusable-responses.md \
                --invert-paths
git reflog expire --expire=now --all && git gc --prune=now --aggressive
```

After rewriting history, **force-push** and rotate any secrets that may have
been visible in the old commits (even though the SOPS file was always encrypted,
it's good practice after a public history change).
