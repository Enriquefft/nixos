# Tools

## Available Tools

### WhatsApp (via Kapso Bridge)
- Send text messages: `kapso-whatsapp-cli send --to +NUMBER --text "message"`
- Check webhook health: `kapso-whatsapp-cli status`
- Incoming messages arrive as JSON on the gateway WebSocket
- Only send when explicitly asked by the user

### Web Search
- Search the web for current information
- Available through Z.AI's Web Search capability

### Web Reader
- Read and summarize web pages
- Available through Z.AI's Web Reader capability
